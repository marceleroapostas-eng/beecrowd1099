# Beecrowd 1099 - Soma de Ímpares Consecutivos II

## Descrição
Programa desenvolvido em Java para calcular a soma dos números ímpares existentes entre dois valores inteiros, para cada caso de teste informado.

## Linguagem
Java

## Entrada
A primeira linha contém um inteiro N, que representa a quantidade de casos de teste. Cada caso de teste contém dois números inteiros X e Y.

## Saída
Imprime a soma dos números ímpares entre X e Y para cada caso de teste.
